# 🚀 वाणीSetu (VaaniSetu) — SIH Feature Roadmap & TODO List

Welcome to the **वाणीSetu** feature tracking roadmap. This list tracks upcoming add-ons and features. We will add/refine features here before implementing them step-by-step.

---

## 📋 Add-on Feature Backlog

- [ ] **1. Interactive Audio FLN Games**
  - Phonetic matching and visual audio flashcards (e.g., animal counting, letter recognition) rendered in local vernacular scripts (Hindi & Santali Ol Chiki).
  - Voice-guided rewards and sound effects for foundational learners.

- [ ] **2. Offline Peer-to-Peer (P2P) Mesh Syncing**
  - Allow local student devices to discover and connect directly to the teacher's edge server over Wi-Fi Direct / Local Hotspot without requiring any cellular Internet connection.

- [ ] **3. Teacher Voice Command Shortcuts**
  - Enable voice commands for teachers (e.g., *"Generate Quiz on Addition"*, *"Mute all students"*, *"Highlight keyword"*) that trigger automated classroom actions.

- [ ] **4. Enhanced UI Animations & Real-Time Waveforms**
  - Add visual live audio waveform indicators (mic visualizer) when teacher/student is speaking.
  - Implement smooth transition animations and mobile-first gesture controls.

- [ ] **5. Android Native Plugin Integrations (Capacitor)**
  - Integrate native Android TTS/STT offline fallbacks via Capacitor bridge.
  - Optimize layout for Android tablets and low-cost smartphones.
